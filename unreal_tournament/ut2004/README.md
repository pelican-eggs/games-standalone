# Unreal Tournament 2004

This is an egg for running an Unreal Tournament 2004 server.

## Note

The server download is ~6GB, most of the download is custom maps to provide a more complete server by default, but this can be changed in the install script to a more bare minimum install.

## Required Server Ports

The server default is 9000, but this can be changed via egg optoins. The game allocates other ports based on this choice, (eg. Game Port: 7777 crt Port: 7787) To ensure the server works please assign the additional ports accordingly. Webserver is also enabled on port 1028, to allow for easier server management locally.
